Je kunt het beste eerst de PDF-bestanden uploaden en daarna pas de drie .md-bestanden aanmaken.

Waarom eerst PDF's uploaden?

• Directe online weergave: GitHub kan .pdf-bestanden direct mooi in de browser tonen, zodat bezoekers en onderzoekers ze meteen kunnen lezen zonder iets te downloaden. Een .docx-bestand (Word) kan GitHub niet zelf openen; dat moeten mensen eerst downloaden. Daarom is PDF de beste keuze (je hoeft het Word-bestand er dan niet per se dubbel bij te zetten, tenzij je wilt dat mensen de tekst makkelijk kunnen kopiëren).
• Werkende links: Zodra de PDF's in je repository staan, kun je er vanuit je drie .md-bestanden (en je README.md) direct naar verwijzen.

Aanbevolen volgorde

1. Stap 1: Upload je PDF-bestanden (in een map /papers/ of /docs/)
	• Klik in je repository op Add file → Upload files.
	• Sleep je overview.pdf en je omgezette Word-document (als .pdf) in het uploadvak.
	• (Tip: Wil je ze netjes in een eigen mapje zoals papers/ zetten? Maak dan eerst via Create new file een tijdelijk bestandje papers/README.md aan, of upload ze nu gewoon direct naar de hoofdmap—dat is voor bezoekers ook heel overzichtelijk).
	• Klik onderaan op de groene knop Commit changes.
2. Stap 2: Maak daarna de drie .md-bestanden in /docs/ aan
	• Maak via Add file → Create new file achtereenvolgens aan:
		• docs/01_The_Substrate.md
		• docs/02_The_Dynamics.md
		• docs/03_The_Cosmology.md
	• Hierin zet je de samenvattingen en belangrijkste formules, met een verwijzing naar de volledige PDF's die je in Stap 1 hebt geüpload.
